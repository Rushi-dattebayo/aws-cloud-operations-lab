# AWS Cloud Operations & Monitoring Lab

A hands-on learning project focused on AWS cloud operations, Linux administration, infrastructure security, monitoring, and troubleshooting.

> **Project status:** Documentation and lab planning completed. Hands-on validation and AWS deployment are pending.

## Objectives
- Understand AWS networking and core infrastructure concepts.
- Practice Linux system administration and troubleshooting.
- Learn IAM least-privilege principles and network security controls.
- Understand monitoring, metrics, alarms, and incident response.
- Document troubleshooting procedures and operational findings.

## Planned Technology Stack
- Amazon Web Services (AWS): VPC, EC2, IAM, CloudWatch
- Linux command-line tools and systemd
- Git and GitHub for documentation and version control

## Repository Structure
- `architecture/` — infrastructure design and architecture notes
- `linux-labs/` — Linux troubleshooting exercises
- `monitoring/` — CloudWatch monitoring and alarm exercises
- `security/` — IAM and network security notes
- `incident-reports/` — incident investigation and remediation reports

## Planned Labs
1. Review network architecture, subnets, routes, and security groups.
2. Practice Linux resource, process, service, and log checks.
3. Design a CloudWatch CPU utilization alarm and document validation.
4. Investigate a simulated web-server outage.
5. Record results, lessons learned, and cost considerations.

## Security and Cost Controls
- Never commit credentials, access keys, passwords, or private keys.
- Enable MFA and follow least-privilege access practices.
- Review AWS account eligibility and service pricing before deployment.
- Avoid unnecessary billable resources and verify resource cleanup.

## Validation and Evidence
Hands-on results, screenshots, architecture diagrams, and test outcomes will be added after the corresponding labs are completed. Planned activities are not represented as completed deployments.

## Learning Outcomes
The goal is to develop practical skills in cloud infrastructure concepts, Linux operations, security fundamentals, monitoring, and structured incident troubleshooting.
